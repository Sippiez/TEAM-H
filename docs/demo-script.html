Presenter notes · Non-technical audience

formER / Live demo script

Four-minute demo

Read the Say lines aloud. Follow the Do cues silently. If you are running late, skip the optional follow-up.

Running order

  1. 0:00 Introduction
  2. 0:30 Open form
  3. 1:10 Explain field
  4. 1:55 Official source
  5. 2:50 Language
  6. 3:20 Close
  7. 3:45 Buffer
Preflight checklist
  • Have the app ready before the slot; do not set up or log in on stage.
  • Use the blank Adult passport application sample.
  • Locate “Surname of parent(s) at their birth” before starting.
  • Test the exact prompts on the presentation network.
  • Keep clearly labelled rehearsal screenshots ready as backup.
  • Never enter real personal information.
0:00–0:30

Introduce the demo

SHOW

Landing page.

SAY

Let’s see how formER helps with a confusing question on a passport application.

0:30–1:10

Open a familiar example

DO

Click “Adult passport application” under “Try a sample form.”

SAY

This field asks for my parents’ surnames at birth. Does that mean their current names, or something different?

DO

Select “Surname of parent(s) at their birth” and let the explanation appear.

1:10–1:55

Make the question understandable

SHOW

Question and explanation side by side.

SAY

The explanation sits beside the question and describes what information belongs here. If I need more help, I can ask a follow-up about this field.

DO

Click “Ask about this field.”

OPTIONAL PROMPT

After the response appears, copy and paste this prompt:

Explain that in one simple sentence.
1:55–2:50

Find the official next step

DO

Open the Ask tab and paste this prompt:

Where can I download the official version of this form?
SAY · WHILE LOADING

formER already knows which application we’re discussing, so I don’t need to repeat its name.

DO

Point to the official source. Open it briefly only if time allows.

SAY

This link lets me check the government source. formER’s help is not an approval decision or a replacement for official instructions.

2:50–3:20

Offer a language choice

DO

Switch the interface to French. Do not wait for another generated response.

SAY

We can switch between English and French. The interface and new explanations use the selected language; the original PDF stays unchanged.

3:20–3:45

Close on the value

SAY

The potential is less uncertainty for applicants and fewer routine questions for staff. formER doesn’t complete or submit applications. It helps people move from “What does this mean?” to “I know what to do next.”

3:45–4:00

Leave room to breathe

SHOW

No extra feature. Use the remaining 15 seconds for delays.

If a live answer fails

SAY

The live answer hasn’t completed, so I won’t present it as verified. Here’s a screenshot from our rehearsal showing this same step.

Then continue the story. Don’t debug on stage.
