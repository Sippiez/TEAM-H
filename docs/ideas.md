# **🎃🍂 CanAI Hackathon: Ideas List Fall 2026🍂🎃**

|  |  |
| --- | --- |
| **Theme** | **Description** |
| <mark>Government Form Helper & Service Navigator | Build an AI assistant that helps people understand and complete government forms and navigate public services more easily. It would explain form fields in plain language, generate a personalized checklist of required documents, answer common questions, and guide users to the right online service, form, or portal. A Manitoba-focused prototype could be demonstrated using publicly available provincial forms and service pages, such as the Manitoba Forms Portal and AccessManitoba. The LLM team already scraped the data for something like this. |
| <mark>Climate & Emergency Response Intelligence Hub | Develop an AI-powered platform that helps governments prepare for and respond to climate-related emergencies such as floods, wildfires, hurricanes, and severe weather events. The solution would integrate weather, environmental, and historical event data to assess risks, generate preparedness recommendations, and support resource planning. |
| <mark>Accessibility Tool: Turn Images into Speech | Build a tool that accepts a photo of a sign, poster, or notice; extracts the text; identifies whether it is in English or French; and reads it aloud in the matching language. The tool also displays the extracted text so users can check it before listening. An optional extension handles images containing both languages.  It has a clear, useful goal that beginners can prototype in two-three days. Teams can combine ready-made OCR and text-to-speech tools without training a model from scratch. Or if some people would like to challenge themselves, build the model from scratch. It also allows different contributions: some participants can work on the image and language pipeline, while others build the interface and test it with real photos. A live demonstration makes both successes and mistakes easy to see. Idea could be extended to extract indirect prompt injection via images, that would potentially change the system message and effectively harm the system. Other extensions could be to extract pre-defined entities from items like a bag of chips has x Calories, x Trans Fat, etc. |
