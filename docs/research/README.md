# Research

Store topic exploration, user needs, feasibility checks, and source links here.
Use descriptive filenames such as `YYYY-MM-DD-short-topic.md`. Distinguish
verified findings from assumptions, and link resulting choices to
[decision records](../decisions/).

Copy this template into a new note when research begins:

```markdown
# Research topic

- Date: YYYY-MM-DD
- Author: TODO

## Question
What are we trying to learn?

## Findings and sources
Summarize evidence and link sources, including relevant dates.

## Assumptions and open questions
What remains uncertain or needs validation?

## Implications and next steps
How does this affect the demo scope or a pending decision?
```
